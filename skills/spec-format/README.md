# Навык spec-format — установка

Навык учит ИИ-агента править ТЗ по единому формату (блоки REQ/Q/DEF, EARS, ID). Один и тот же каталог работает в Claude Code и Codex; бинарник spec-audit для него не нужен.

## Установка в проект с ТЗ

1. Скопируйте каталог `spec-format` (без этого README он тоже работает) в корень проекта:
   - Claude Code: `.claude/skills/spec-format/`
   - Codex: `.agents/skills/spec-format/`
   Для всех своих проектов сразу — в `~/.claude/skills/` и `~/.codex/skills/`.
2. Добавьте в корневой `AGENTS.md` проекта (для Claude Code — в `CLAUDE.md` или симлинк `CLAUDE.md → AGENTS.md`) одну строку, подставив каталог ТЗ:

   ```markdown
   Любое изменение файлов в `<каталог ТЗ>/` — только по навыку spec-format: прочитай его до правки.
   ```

   Без этой строки агент включает навык по своему решению; с ней — при каждой правке ТЗ.

## Обновление

Замените каталог новой версией целиком. Навык не хранит состояния.
