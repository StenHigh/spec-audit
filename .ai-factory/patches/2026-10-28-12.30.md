# Признаки потерянного run и принадлежность производного HTML

**Дата:** 2026-10-28 12:30 Europe/Berlin
**Файлы:** tool/publish.go, tool/bundle.go, tool/publication_safety_test.go
**Серьёзность:** medium

## Проблема

Latest с явным CONFIG пропускал B после потери manifest и молча публиковал A.
Автопоиск того же хранилища правильно отказывал.
Bundle v3 отказывал при неизвестной паре notes/report.json и notes/report.html.
Это блокировало создание audit backup для безопасной очистки.

## Причина

Reader явного CONFIG пропускал ENOENT без общей проверки сохранённых признаков аудита.
Новая проверка производного HTML использовала суффикс имени и соседний report.json.
Она не требовала принадлежности пары настоящему прямому run.

## Решение

ReadPublicationRuns вызывает savedRunEvidence при потерянном manifest.
Ошибки чтения и сохранившийся state/inventory/journal дают отказ до OUT.
Historical по-прежнему рассматривает только выбранный run.
Validator schema 3 связывает HTML с прямым RUN_ID, Manifest и Report.
Version, SnapshotID и RunID проверяются строго; повреждение Report не даёт обхода.
Неизвестные пары сохраняются, даже если JSON не является Report или содержит копию настоящего Report.
Сохранённые bytes/mode остаются частью backup и защиты cleanup.
Диагностика использует slog.Debug с префиксами [FIX:publication] и [FIX:bundle-report].

## Предотвращение

Проверяйте одну норму через явный CONFIG и автопоиск.
Отказ от fallback должен учитывать потерянный файл, а не только повреждённый JSON.
Имя файла не доказывает его принадлежность аудиту или производному представлению.
Проверяйте root/deep пары, неизвестный JSON и копию настоящего Report.
Новые регрессии сначала отказали за 9.441s, затем прошли за 11.715s.
Они проверяют archive/citations, независимый historical и три независимых признака потерянного run.
Backup/restore и два apply сохраняют bytes/mode неизвестных файлов.
Повторное read-only ревью не выявило новых подтверждённых дефектов.

Полный `go test ./tool -count=1 -json` прошёл за 461.642s на Linux.
209 тестов верхнего уровня прошли; 10 необязательных проверок пропущены без внешних входов/браузерного fixture.
Vet и сборка прошли; hashes и состав входов не изменились во время полного запуска.
Заключительное read-only ревью не выявило новых подтверждённых дефектов.
Frozen contracts, Original Request, CLAUDE symlink и зависимости сохранены.
