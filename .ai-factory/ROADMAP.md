## После ближайших этапов

- [ ] **Несколько разделов и обзор корпуса.** Контракт полноты инвентаря, настоящие разделы/заголовки ТЗ, сводная карта требований, реализации, известных GAP и достаточности assertions. Отдельно определить выявление противоречий норм и неописанного поведения; отсутствие связи не объявлять дефектом. Текущие показатели относятся к одному run и группируются по файлам.
- [ ] **Инкрементальная актуальность.** Обновлять затронутые требования, связи и проверки с сохранением происхождения и истории; не переносить старые «зелёные» выводы на изменённый код/ТЗ без основания.
- [ ] **Приёмка замены старого AI re-audit на пилоте.** По [спецификации применения](../docs/smsplace-adoption.md): список прежних гарантий и их замен, контрольный рабочий цикл, rollback. Старый CI временно сохраняется; текущая ограниченная обкатка не является разрешением удалить прежний инструмент.
- [ ] **Пробное преобразование бизнес-ТЗ.** Отдельная спецификация применения, один пробный раздел, сравнение обязанностей до/после. Не смешивать с универсальным ядром или считать автоматически выполненным после SDK; подготовка к ISO не равна соответствию ISO.

## Исследования, не разрешение на реализацию

`php-typed` остаётся опцией по требованию: решение владельца 2026-09-16 после нейтрального сравнения. Повторное сравнение — только на scope с интерфейсами/биндингами/фасадами, где роли без SDK дают `unknown`; до такого scope в SDK не вкладываться. Notes/compact остаются test-only: рабочая интеграция не принята. Уменьшение JSON не доказывает экономию токенов/денег и сохранение качества; нужен сопоставимый контроль с явными критериями перехода. Новые языки и фреймворки добавляются по конкретной потребности. Graphify/graph/cache, автоматические задачи трекера и модельный API в бинарнике не входят в ближайшую работу.

Ошибки извлечения обязанностей, применимости требований и достаточности assertions продолжаем превращать в независимые регрессии. Инструмент развивается spec-first и проверяется на собственной спецификации, а не только на пилоте.
