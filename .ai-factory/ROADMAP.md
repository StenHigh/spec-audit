# Project Roadmap

> Самостоятельный инструмент аудита Markdown-ТЗ по коду и assertions тестов: AI-роли делают смысловой анализ, Go-бинарник проверяет свидетельства и хранит происхождение; цель — рабочий режим на полном ТЗ проекта с одной картой состояния и честной динамикой GAP. Критерии закрытия каждого milestone — [LESSONS.md](LESSONS.md), раздел «Детализация очереди».

## Milestones

- [x] **Инкрементальный перепрогон после изменения кода** — `prepare … since PREV_RUN` (§50, REQ-SA-050): роли получают только новые, GAP и затронутые нормы; остальные переносятся с провенансом и пометкой `carried`; полный run — эталон; критерий «≤ ⅓ полного» выполнен на пилоте (finance: 32 %)
- [x] **Перепрогон затронутых scope одной командой** — `rerun RUN_ID CONFIG...` (§54, `TestRerunBatch`): инкрементальный run по каждому scope от `baseline_run` или последнего решённого, очередь заданий одним ответом
- [x] **Свежесть accepted-индекса при смене группы файла** — журнал индекса version 2 с классификацией источников (§55, `TestReferenceGroupFreshness`); старые журналы читаются без классификации
- [x] **Релизная квалификация без `-short` на обеих платформах** — полный набор в release.yml и ci.yml, Actions по SHA, строгий `update`, литеральный вектор `counts` (§56)
- [x] **Установка skill через staging** — свежая копия собирается в `.spec-audit/.skill-staging-*` и публикуется одним rename (§57, `TestSkill/interrupted_install_leaves_nothing`); прерванная установка не оставляет каталога без receipt
- [x] **Фильтр трейтов в PHP-экспортёре** — `FactSink` отбрасывает факты с путём вне `files` (§58); контейнерная приёмка `TestExternalTypedPlain/trait_outside_files` показала, что сценарий review на PHPStan 2 не воспроизводится
- [x] **Контракт первой справочной цитаты** — §59: `navigation.section` = первая нормативная цитата, справочный файл норм не считает; `Source`, журнал и `snapshot_id` не тронуты (`TestReferenceSources/report`)
- [x] **Бенчмарки и повторное чтение файлов** — `tool/bench_test.go` (96 норм, 768 цитат, 48×200 КБ) и `sourceCache` на команду (§60): `status` 300→63 мс, 793→123 МБ аллокаций; `lineQuote`/HTML не трогались — узкого места нет
- [ ] **Токены ролей** — измерить долю чтения контекста (files.json, протокол, промпт, код) при 0,25–0,42 M на роль и сократить без сужения списка файлов
- [ ] **Сравнение метода с простым AI-baseline** — один агент / две роли без инфраструктуры / полный spec-audit на независимых наборах; если полный процесс не выигрывает — упрощать
- [ ] **`php-typed` на interface-heavy scope** — единственное условие возврата к SDK (решение владельца 2026-09-16)
- [ ] **Пробное преобразование бизнес-ТЗ** — отдельная спецификация применения, один пробный раздел, сравнение обязанностей до/после
- [ ] **Приёмка замены старого AI re-audit на пилоте** — список прежних гарантий и их замен, контрольный цикл, rollback; старый CI сохраняется до решения владельца
- [x] **Ограниченный цикл аудита и карта одного run** — Go CLI, declared/accepted-индекс, независимые роли, согласование хоста, HTML-карта run
- [x] **PHP/Laravel SDK и его сравнение на пилоте** — `php-typed`, контракт `sdk/3`, нейтральный результат сравнения
- [x] **Поставка и рабочий цикл из чистой AI-сессии** — подписанный релиз, `update`, `skill install|update`, launcher; 16 чистых прогонов на пилоте
- [x] **Публикация для заказчика** — `publish OUT_DIR CONFIG...`: статический сайт с картой корпуса, историей решённых run по времени и копиями всех отчётов; для любого сервера или общей папки
- [x] **Несколько разделов и обзор корпуса** — 11 scope и 681 норма на пилоте, `keep` для больших разделов, `overview`/`corpus` с GAP, кросс-scope памятью и динамикой между решениями
