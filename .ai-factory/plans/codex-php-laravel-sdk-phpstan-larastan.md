## Риски
- Larastan bootstrap исполняет код приложения: fail-fast env отводит DB/Redis/queue/cache/mail/log, но не запрещает исходящий HTTP из `boot()`; сетевая изоляция — за оператором/сетью контейнера, фиксируется как limitation (SA-034). Синтетика демонстрирует отказ через `network_mode: none`.
- Запись Laravel в `storage/` не обнаруживается, если `storage` вне code.paths; `bootstrap/cache` покрыт обязательным `bootstrap/app.php` в manifest.
- ProviderRepository переписывает `bootstrap/cache/services.php` при устаревшем манифесте → ожидаемый отказ «снимок изменился» на проекте без актуального `package:discover`; документируется.
- Имена параметров `%allConfigFiles%`/`%bootstrapFiles%`/`%scanFiles%` и `FileNode`/`StubFilesProvider` — внутренние детали PHPStan, могут меняться между минорами; при отсутствии — DI-контейнер не собирается → явный отказ, не тихий пустой результат.
- Размер sink-сообщения (двойное JSON-кодирование) может упереться в `maxResult` 4 MiB на 64 файлах → отказ, не потеря; spike измеряет; fallback — файл из sink (недокументированный путь) только при подтверждённой проблеме.
- Холодный запуск без result cache + bootstrap + reflection — минуты и до 2G на пилоте; дефолты уточняются spike; при превышении — сужение выборки или `timeout_seconds` до 900, не расширение §8.
- `echo`/deprecations в провайдерах загрязняют stdout → разбор JSON падает → отказ; `-d display_errors=stderr`, `--no-progress` снижают риск.
- `requiredJSON` требует все поля: любое новое поле envelope ломает фикстуры — версия `sdk/3` фиксируется, изменения только через `sdk/4`.
- Первый `php-typed` делает текущий host review outdated — требуемое поведение (SA-033); протокол велит импортировать до review.
- Mock-тесты не ловят ошибок PHP-стороны; до синтетических контейнеров единственная проверка экспортёра — пилотный контейнер (T3, T5, T10).
- Синтетический Laravel требует `composer install` с сетью и совместимых версий на дату выполнения; `composer.lock` коммитится, обновление потребует перезаписи фикстур.
- Хост может воспринять подсказки как доказательство связи — смягчение: протокол, бейдж, отсутствие подсказок в `Links`/метриках.
- Пилотные envelope содержат бизнес-имена — только в `.local/`; проверки `git status`/`rg smsplace` в T3, T10, T13, T16.
- Frozen-контроль может содержать ожидания, которые PHPStan/Larastan не подтвердят (facade → класс vs virtual); ожидания не переписываются — расхождение фиксируется как известное ограничение (T15).
