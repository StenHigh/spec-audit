## Original Request
Уроки чистой сессии (ROADMAP): 1) команда `validate CONFIG RUN_ID TASK_ID RESULT` — проверка формы ответа роли (схема, диапазоны цитат, enum, полнота ID) без записи в state и без изменения submit; 2) protocol.txt — убрать Codex-специфичный `apply_patch`, разрешить любой инструмент записи хоста и описать сборку большого результата (mapper 354 КБ не влезал в один Write); 3) провенанс версии бинарника — `tool_version` в manifest при prepare и в state при каждой записи, предупреждение/отказ при смене версии внутри run (форматы §1–10 frozen — оформить как расширение §18/§9-совместимое); 4) попутно reconcile: `freshness: null` сразу после apply и вынос revision/clarity records[].requirement на верхний уровень. Пункты про reference-only файлы ТЗ вне лимита 64 и разбиение больших accepted-наборов при scopes: [] — вне этого плана (отдельное решение владельца).
