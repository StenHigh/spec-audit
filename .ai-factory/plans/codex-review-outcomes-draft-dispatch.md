## Риски
- `draft` печатает `basis_sha256` момента вызова; любое изменение state (retry, receipt) до `review … DECISION` даёт отказ CAS по §14 — это ожидаемое поведение, SKILL.md говорит перечитать `draft`.
- Пустые состояния в скелете не проходят `checkVerdict` — незаполненный скелет отклоняется с именем нормы, не записывается; тест это закрепляет.
- Материализация dispatch пишет в run после `saveState`: сбой записи каталога оставляет run пригодным (`tasks` и повторный `retry`), но `prepare` возвращает ошибку — launcher видит её и не запускает роли на неполных каталогах.
- `dispatch/host/` — соглашение SKILL.md, бинарник его не создаёт и не проверяет.
- Если хост ранее выбрал собственный `review_id`, совпадающий с `host-review-NNN` черновика, конфликт байт по §14 отклонит запись — SKILL.md велит оставлять `review_id` черновика и не выдумывать свой.
