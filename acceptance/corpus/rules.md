# Требования демонстрационного среза

Конкретное хранилище Store предоставляет внешнее приложение.
Его реализация и тесты не входят в данный срез исходников.

### REQ-DEMO-001 — Инверсия

Условие: вызвана Flip с произвольным значением bool.
Требование: результат должен быть логическим отрицанием входного значения.
Проверка: проверить точный результат для false и true.

### REQ-DEMO-002 — Удвоение

Условие: вызвана Double(7).
Требование: результат должен быть равен 14.
Проверка: сравнить результат с 14 на равенство.

### REQ-DEMO-003 — Модуль

Условие: вызвана Absolute(-3).
Требование: результат должен быть равен 3.
Проверка: сравнить результат с 3 на равенство.

### REQ-DEMO-004 — Сохранность

Условие: Save(store, "note") вернула nil.
Требование: строка "note" должна оставаться доступной в том же хранилище после перезапуска процесса.
Проверка: после успешной записи завершить процесс и прочитать строку из того же хранилища новым процессом.

### REQ-DEMO-005 — Представление имени

Условие: вызвана Normalize(" Ada ").
Требование: результат должен содержать имя в стандартном представлении.
Проверка: сравнить результат со стандартным представлением имени.
