Динамика

Сравнение решённого run каждого scope с предыдущим решённым run того же scope: норма сравнивается только при том же содержании и revision; закрыто — была GAP, теперь нет; открылось — наоборот; изменилось — GAP в обоих, но состояния разные. Это разность двух суждений хоста на двух snapshot, не измерение качества фикса.
